# Security policy

Vicaro is beta software. Please do not open a public issue for a security problem.

Email [hello@creativeducks.com](mailto:hello@creativeducks.com) with:

- The affected version of the helper and extension.
- What an attacker could do, and what access they need.
- Steps to reproduce, with secrets and personal data removed.
- Any suggested fix or mitigation.

You will get an acknowledgement as soon as possible. The latest beta is the supported
version. There is no bug bounty at this stage.
